# Directory Overview
This directory is for creating notes relating to a course in database management systems. The notes are for use with the Obsidian app and therefore should follow Obsidian/Markdown formatting.

# Key Files

*   `Intro.md`: This is a comprehensive introduction to database concepts. It covers:
    *   The definition of data and databases.
    *   Examples of database usage.
    *   Types of data (Structured, Semi-structured, Unstructured).
    *   The importance of studying databases.
    *   An overview of Relational and Non-Relational databases.
    *   Key concepts and terminology like Data Models and Schema.
    *   The advantages of using a Database Management System (DBMS).
    *   Different human roles related to databases.
    *   The phases of database design.
    *   The 3-schema database architecture and data independence.

# Usage

The files in this directory are intended to be read for learning about databases. The `Intro.md` file provides a solid foundation for understanding the fundamentals of database systems.
