## Directory Overview
This directory contains course materials for a networking and cryptography course, ELEC 473. The content consists of lecture notes in Markdown format and a PDF assignment file. The notes cover fundamental concepts in network security and cryptography. 
## Key Files
*   `Advanced-Encryption-Standard.md`: Describes the Advanced Encryption Standard (AES), a modern and secure encryption standard. It covers key sizes, block sizes, and different encryption modes (ECB, CBC, CFB, OFB, CTR).
*   `Assignment-2.md`: This file appears to be a workspace for solving the problems in the second assignment, covering topics like the Euclidean algorithm, repeated squaring, modular arithmetic, RSA, and Elliptic Curve Cryptography.
*   `Data-Encryption-Standard.md`: Explains the Data Encryption Standard (DES), a symmetric-key encryption algorithm. It details the Feistel network structure used in DES.
*   `Cryptography/ElGamal-Cryptosystem.md`: Details the ElGamal cryptosystem, which is built on the Diffie-Hellman key exchange protocol and relies on the difficulty of the Discrete Logarithm problem.
*   `Cryptography/Elliptic-Curve-Cryptography.md`: Provides an introduction to Elliptic Curve Cryptography (ECC), defining an elliptic curve over real numbers.
*   `Cryptography/Perfect-Secrecy.md`: Discusses the concept of perfect secrecy in cryptography, as defined by Claude Shannon. It explains the conditions required for a cryptosystem to have perfect secrecy, using the one-time pad as an example.
*   `Cryptography/RSA-Cryptosystem.md`: Explains the RSA cryptosystem, a public-key algorithm based on the difficulty of factoring large numbers. It covers key generation, encryption, and decryption.
*   `Data_Integrity/Digital-Signature.md`: Covers digital signatures, their properties (integrity, authenticity, non-repudiation), and security goals. It also describes the RSA signature scheme.
*   `Number_Theory/Euclidean-Algorithm.md`: Explains the Euclidean algorithm for finding the greatest common divisor of two integers and the extended Euclidean algorithm. It also touches on prime numbers and factorization.
*   `Number_Theory/Intractible-Problems.md`: Discusses computationally hard problems in number theory that are the foundation of modern cryptography, such as the Discrete Logarithm Problem and the Integer Factorization Problem.
*   `Number_Theory/Modulo-Arithmetic.md`: Covers the fundamentals of modular arithmetic, including groups, Euler's totient function, Euler's theorem, Fermat's Little Theorem, and the Chinese Remainder Theorem.
*   `Security/Network-Security.md`: Provides an introduction to network security, covering the CIA triad (Confidentiality, Integrity, Availability) and the importance of network security protocols.
*   `Security/User-Authentication.md`: Discusses different methods of user authentication, including password-based authentication and its vulnerabilities.
*   `media/`: This directory contains images that are embedded in the markdown notes to illustrate concepts.
