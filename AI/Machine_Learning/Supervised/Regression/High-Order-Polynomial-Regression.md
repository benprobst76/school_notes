In addition to [[Constant-Regression]] and [[Linear-Regression]], we can use more “curvy” curves (generated by more complicated models) to fit a curve to the given data. Polynomials with different orders (M determines the order): $$y(x,w)=w_0+w_1x+w_2x^2+...+w_Mx^M=\sum^M_{j=0}w_jx^j$$
What M should we pick? M = 0, 1, 2 corresponds to a constant, linear, second order polynomial model respectively. 
- e.g., second-order polynomials or higher-order polynomials

When the order of polynomials increases, models become more complex and training error keeps decreasing but the test error will increase.

The situation of overfitting can be improved if you have more training data. Think about picking one specific model (e.g., a model with M=9), how your training/test error curves look like if y-axis is root mean square errors and x-axis is the size of training data. 
### Values of Weights w under Different Models
![[Pasted image 20251006144848.png]]
When there is not enough training data (here 10 data points), as M increases, the magnitude of the weights w typically get larger.  
- Constraining the magnitude of weights is a typical way to prevent overfitting. It controls the complexity of models.  
- Remember [[Support-Vector-Machine]] naturally does this in some degree---it minimizes weight vectors || 𝑤 || directly (subject to some constraints).  
- If you start your weights with small values, “stop (training)earlier” corresponds to constrain weight values to be small and can control overfitting. (This is widely used in training neural nets.)  
- One technique that is often used to control over-fitting is [[Regularization]].
