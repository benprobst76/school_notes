## [[Clustering]] 
using relations between things to make intuitive guesses. If a person from this town likes this book they might like this movie. 
Inputs are continuous or categorical. The goal is to group data cases into a finite number of clusters. In each cluster all cases have very similar inputs. Example - clusters of emerging news/tweets.
