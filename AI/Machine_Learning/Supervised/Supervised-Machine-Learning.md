- Collect lots of examples that specify the output for a given input
- An algorithm reads the examples and creates a model to solve the problem and predict outputs on future inputs 
- When the data changes the program can change accordingly by training on the new data
- Example: [[Classification]], [[Regression]], and [[Time-Series-Prediction]] 

**Training stage:** Trying to find the parameters, decision boundaries/surfaces
**Validation stage:** Selecting or averaging models; picking the model that predicts the output best. 
**Testing stage:** Predict the label of a new datapoint.
